Features

Everything you need for safe AI-assisted development.

🔒

Containment Strategies

Choose your isolation level: Git worktrees for lightweight tasks, Docker for maximum security, or local execution for rapid iteration.

📋

Cryptographic Receipts

Every task generates a tamper-proof audit trail with task metadata, diffs, test results, and safety verdicts.

🔌

OpenCode Integration

Native Go adapter replaces shell scripts. Plugin tools let you submit tasks and check receipts without leaving your editor.

🛡️

Permission Control

Granular allowlists for file access. Environment variable overrides for secure CI/CD pipelines.

Quick Start

Get up and running in under a minute.

# Build the binary go build -o c1-forged ./cmd/c1-forged/ # Initialize workspace c1-forged init # Run a task through the safety pipeline c1-forged run "fix the login bug" --commands "go test ./..." # Check the receipt c1-forged status
# config/c1-forge.yaml forge: runner: mode: opencode command: opencode opencode: model: anthropic/claude-sonnet-4-5 dangerously_skip_permissions: false permission_allowlist: - "/project/src/*.go" - "/project/tests/*"
